# Образовательная платформа (education-platform)

## Описание

Веб-приложение для онлайн-обучения, где преподаватели могут создавать курсы, добавлять уроки и материалы, а ученики — просматривать уроки, скачивать материалы, сдавать домашние задания и общаться в комментариях.

---

## Основные функции

- Регистрация и вход пользователей (ученик/преподаватель/админ)
- Просмотр и управление курсами
- Просмотр уроков, видео и материалов
- Загрузка материалов к уроку (преподаватель)
- Сдача домашнего задания (ученик)
- Комментарии к уроку и домашним заданиям
- Уведомления
- Лента ответов, расписание, тесты

---

## Требования

- Node.js (v18+)
- PostgreSQL (v13+)
- npm

---

## Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/your-username/education-platform.git
cd education-platform
```

### 2. Установите зависимости

```bash
npm install
```

### 3. Настройте базу данных

- Создайте базу данных `education_platform` в PostgreSQL.
- Импортируйте структуру из файла [`docs/schema.sql`](docs/schema.sql):

```bash
psql -U postgres -d education_platform -f docs/schema.sql
```

- Проверьте настройки подключения к БД в [`server/config/db.js`](server/config/db.js) (логин, пароль).

### 4. Запустите сервер

```bash
node server/server.js
```

Сервер будет доступен по адресу: [http://localhost:3000](http://localhost:3000)

---

## Структура проекта

- `frontend/` — HTML, CSS, JS (клиентская часть)
- `server/` — серверная часть (Express, маршруты API)
- `uploads/` — загруженные файлы (материалы, домашние задания)
- `docs/` — документация и SQL-скрипты

---

## Как работать с приложением

1. Откройте [http://localhost:3000/auth.html](http://localhost:3000/auth.html) для регистрации или входа.
2. После входа вы попадёте на страницу "Мои курсы".
3. Преподаватель может создавать курсы, добавлять уроки и материалы.
4. Ученик может просматривать курсы, скачивать материалы, сдавать домашние задания.
5. Все файлы сохраняются в папке `uploads`:
    - Материалы уроков — в `uploads/materials`
    - Домашние задания — в `uploads/homeworks`
6. Для просмотра урока перейдите в курс и выберите нужный урок.
7. Для сдачи ДЗ используйте форму "Отправить домашнее задание" на странице урока.

---

## Примечания

- Для отправки email (например, восстановления пароля) настройте переменные окружения для почты в файле `.env` или прямо в коде.
- Для продакшена рекомендуется использовать Tailwind CSS через npm/PostCSS, а не CDN.
- Все файлы, загруженные пользователями, доступны только через защищённые маршруты.
